# 文件类型风险矩阵

## 风险等级分类

| 等级 | 含义 | 检测重点 |
|------|------|----------|
| 高危 | 可直接执行或被系统自动执行 | 文件头签名、哈希、PE 导入表 |
| 中危 | 需要特定环境执行，但可被滥用 | 内容模式匹配、文件名特征 |
| 低危 | 通常不含可执行代码 | 文件头签名验证 |
| 关注 | 容器格式，可能包含危险内容 | 内部文件列表检查 |

## 文件类型风险矩阵

### 高危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .exe | Windows 可执行文件 | 最常见的恶意软件载体 | 文件头、哈希、PE 导入表 |
| .dll | 动态链接库 | 可被注入到合法进程 | 文件头、哈希、PE 导入表 |
| .scr | 屏幕保护程序 | 本质是 EXE，常被伪装 | 文件头、哈希、PE 导入表 |
| .sys | 驱动文件 | 可加载内核模块，权限极高 | 文件头、哈希、PE 导入表 |
| .cpl | 控制面板项 | 本质是 DLL，可被双击执行 | 文件头、哈希 |
| .ocx | ActiveX 控件 | 可被网页/文档调用执行 | 文件头、哈希 |
| .com | DOS 可执行文件 | 老式可执行格式，仍可运行 | 文件头、哈希 |
| .msi | Windows 安装包 | 可执行安装操作，可携带恶意 payload | 文件头、哈希、内部内容 |
| .lnk | Windows 快捷方式 | 可指向任意可执行文件，常用于社工 | Shell Link 签名 + 目标路径解析 |
| .jar | Java 可执行包 | 可携带恶意 Java 代码 | ZIP 签名、内部 Manifest |
| .hta | HTML Application | 双击即执行 VBScript/JScript | 内容模式匹配、文件头 |
| .wsf | Windows Script File | 可混合多种脚本语言执行 | 内容模式匹配 |
| .wsh | Windows Script Host 配置 | 可指定脚本执行参数 | 内容模式匹配 |

### 中危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .js / .jse | JavaScript | 可通过 WScript 执行，可下载运行恶意代码 | 内容模式匹配 |
| .ps1 | PowerShell 脚本 | 可下载执行、持久化、注入 | 内容模式匹配 |
| .psm1 | PowerShell 模块 | 可被 Import-Module 加载执行 | 内容模式匹配 |
| .vbs | VBScript | 可通过 WScript 执行，操作文件系统/注册表 | 内容模式匹配 |
| .vbe | VBE 编码脚本 | VBS 编码变体，需先解码 | 编码检测 + 内容模式 |
| .bat | 批处理脚本 | 可执行任意命令，可下载运行恶意代码 | 内容模式匹配 |
| .cmd | 命令脚本 | 同 .bat | 内容模式匹配 |
| .py | Python 脚本 | 可执行任意代码，可下载和持久化 | 内容模式匹配 |
| .sh | Shell 脚本 | 可执行任意命令，可建立反向连接 | 内容模式匹配 |
| .reg | 注册表脚本 | 可修改系统注册表，实现持久化 | 内容检查（Run 键） |

### 低危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .pdf | PDF 文档 | 可携带 JS 脚本，需特定条件触发 | 文件头签名 |
| .doc | Word 文档（旧格式） | 可携带宏病毒 | 文件头签名（OLE）+ 宏流名 |
| .docx | Word 文档（新格式） | 宏风险较低，但可包含 OLE 对象 / 隐藏 VBA | 文件头签名（ZIP）+ vbaProject.bin |
| .docm | Word 宏文档 | 显式启用宏，可携带恶意 VBA | 文件头签名 + 宏流 + 自动执行标记 |
| .xls | Excel 表格（旧格式） | 可携带宏病毒 | 文件头签名（OLE）+ 宏流名 |
| .xlsx | Excel 表格（新格式） | 宏风险较低，但可隐藏 VBA | 文件头签名（ZIP）+ vbaProject.bin |
| .xlsm | Excel 宏表格 | 显式启用宏 | 文件头签名 + 宏流 + 自动执行标记 |
| .rtf | 富文本格式 | 可携带 RTF 漏洞利用 | 文件头签名 |
| .html | HTML 文件 | 可包含恶意 JS，需浏览器打开 | 内容检查（script 标签） |
| .htm | HTML 文件 | 同 .html | 内容检查 |

### 关注文件类型（容器格式）

| 扩展名 | 类型 | 风险说明 | 检测重点 | 当前实现 |
|--------|------|----------|----------|----------|
| .zip | ZIP 压缩包 | 可包含任意文件 | 内部文件列表 + 文件头 | ✅ 完整（namelist + 内存读头） |
| .rar | RAR 压缩包 | 同 .zip | 内部文件列表 | ⚠️ 依赖外部工具，仅提示 |
| .7z | 7Z 压缩包 | 同 .zip | 内部文件列表 | ⚠️ 依赖外部工具，仅提示 |
| .tar | TAR 归档 | 可包含任意文件 | 内部文件列表 | 未解析 |
| .gz | GZIP 压缩 | 通常压缩单个文件 | 文件头签名 | 未解析 |
| .iso | 磁盘映像 | 可包含完整文件系统 | 内部文件列表 | 未解析 |
| .img | 磁盘映像 | 同 .iso | 内部文件列表 | 未解析 |

> RAR/7Z/ISO 等格式的内检依赖外部工具（`unrar` / `p7zip`），当前版本仅记录 `low` 提示，不阻塞扫描。若需要完整内检，可安装对应工具后由 Agent 手动调用。

## 默认文件过滤策略

根据扫描场景，推荐不同的文件过滤组合：

| 场景 | 推荐过滤 | 原因 |
|------|----------|------|
| 通用扫描 | 全部类型 | 不遗漏任何潜在威胁 |
| 快速排查 | exe,dll,scr,sys,com,lnk,hta | 聚焦最危险的文件类型 |
| 脚本排查 | js,ps1,psm1,vbs,vbe,bat,cmd,py,sh,hta,wsf,wsh | 聚焦脚本类威胁 |
| 下载目录 | exe,dll,msi,js,ps1,vbs,bat,cmd,zip,rar,7z,lnk,scr,hta,docm,xlsm | 覆盖下载常见威胁（含宏文档） |
| U 盘扫描 | exe,dll,scr,sys,com,lnk,js,ps1,vbs,bat,hta,wsf | 聚焦可执行和脚本威胁 |
| 项目目录 | py,sh,bat,ps1,js,psm1 | 聚焦项目脚本安全 |
| 宏文档审计 | docm,xlsm,doc,xls,rtf | 聚焦宏/漏洞文档 |

## 扩展名与实际类型不一致风险

某些扩展名可能被系统当作不同类型处理：

| 扩展名 | 系统可能当作 | 风险 | 检测方法 |
|--------|-------------|------|----------|
| .exe → .txt | 用户以为是文本，实际可执行 | 高 | 文件头 MZ + 扩展名安全类型 |
| .scr → .jpg | 用户以为是图片，实际可执行 | 高 | 文件头 MZ + 扩展名图片类型 |
| .com → .doc | 用户以为是文档，实际可执行 | 高 | 文件头 MZ + 扩展名文档类型 |
| .lnk | 显示为目标文件名，实际指向任意路径 | 高 | Shell Link 签名 + 目标解析 |
| .jar → .zip | 用户以为是压缩包，实际可执行 | 中 | ZIP 签名 + 扩展名 .jar（白名单） |
| .docx → .zip | 用户以为是压缩包，实际是文档 | 低 | ZIP 签名 + 扩展名 .docx（白名单） |
| .docm → .zip | 用户以为是压缩包，实际是宏文档 | 中 | ZIP 签名 + 扩展名 .docm（白名单） |
| .xlsm → .zip | 用户以为是压缩包，实际是宏表格 | 中 | ZIP 签名 + 扩展名 .xlsm（白名单） |
| .hta → .html | 用户以为是网页，实际双击执行 | 高 | 内容模式匹配 |
| .vbe → .vbs | 用户以为是 VBS，实际是编码变体 | 中 | 扩展名 + 编码检测 |

文件头签名检测 + 白名单可有效识别这类伪装，同时避免对正常 ZIP 容器（docx/xlsx/docm/xlsm/jar）误报。
