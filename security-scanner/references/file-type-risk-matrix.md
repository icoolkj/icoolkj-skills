# 文件类型风险矩阵

## 风险等级分类

| 等级 | 含义 | 检测重点 |
|------|------|----------|
| 高危 | 可直接执行或被系统自动执行 | 文件头签名、哈希、PE 结构 |
| 中危 | 需要特定环境执行，但可被滥用 | 内容模式匹配、文件名特征 |
| 低危 | 通常不含可执行代码 | 文件头签名验证 |
| 关注 | 容器格式，可能包含危险内容 | 内部文件列表检查 |

## 文件类型风险矩阵

### 高危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .exe | Windows 可执行文件 | 最常见的恶意软件载体 | 文件头、哈希、PE 结构、导入表 |
| .dll | 动态链接库 | 可被注入到合法进程 | 文件头、哈希、PE 结构、导入表 |
| .scr | 屏幕保护程序 | 本质是 EXE，常被伪装 | 文件头、哈希、PE 结构 |
| .com | DOS 可执行文件 | 老式可执行格式，仍可运行 | 文件头、哈希 |
| .msi | Windows 安装包 | 可执行安装操作，可携带恶意 payload | 文件头、哈希、内部内容 |
| .lnk | Windows 快捷方式 | 可指向任意可执行文件，常用于社工攻击 | 快捷方式目标路径解析 |
| .jar | Java 可执行包 | 可携带恶意 Java 代码 | 内部内容、Manifest 检查 |

### 中危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .js | JavaScript | 可通过 WScript 执行，可下载和运行恶意代码 | 内容模式匹配 |
| .ps1 | PowerShell 脚本 | 功能强大，可下载执行、持久化、注入 | 内容模式匹配 |
| .vbs | VBScript | 可通过 WScript 执行，可操作文件系统和注册表 | 内容模式匹配 |
| .bat | 批处理脚本 | 可执行任意命令，可下载和运行恶意代码 | 内容模式匹配 |
| .cmd | 命令脚本 | 同 .bat | 内容模式匹配 |
| .py | Python 脚本 | 可执行任意代码，可下载和持久化 | 内容模式匹配 |
| .sh | Shell 脚本 | 可执行任意命令，可建立反向连接 | 内容模式匹配 |
| .reg | 注册表脚本 | 可修改系统注册表，实现持久化 | 内容检查（注册表键值） |

### 低危文件类型

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .pdf | PDF 文档 | 可携带 JS 脚本，但需特定条件触发 | 文件头签名 |
| .doc | Word 文档（旧格式） | 可携带宏病毒 | 文件头签名 |
| .docx | Word 文档（新格式） | 宏病毒风险较低，但可包含 OLE 对象 | 文件头签名 |
| .xls | Excel 表格（旧格式） | 可携带宏病毒 | 文件头签名 |
| .xlsx | Excel 表格（新格式） | 宏病毒风险较低 | 文件头签名 |
| .html | HTML 文件 | 可包含恶意 JS，但需浏览器打开 | 内容检查（script 标签） |
| .htm | HTML 文件 | 同 .html | 内容检查 |

### 关注文件类型（容器格式）

| 扩展名 | 类型 | 风险说明 | 检测重点 |
|--------|------|----------|----------|
| .zip | ZIP 压缩包 | 可包含任意文件，常用于传播恶意软件 | 内部文件列表 |
| .rar | RAR 压缩包 | 同 .zip | 内部文件列表 |
| .7z | 7Z 压缩包 | 同 .zip | 内部文件列表 |
| .tar | TAR 归档 | 可包含任意文件 | 内部文件列表 |
| .gz | GZIP 压缩 | 通常压缩单个文件 | 文件头签名 |
| .iso | 磁盘映像 | 可包含完整文件系统 | 内部文件列表 |
| .img | 磁盘映像 | 同 .iso | 内部文件列表 |

## 默认文件过滤策略

根据扫描场景，推荐不同的文件过滤组合：

| 场景 | 推荐过滤 | 原因 |
|------|----------|------|
| 通用扫描 | 全部类型 | 不遗漏任何潜在威胁 |
| 快速排查 | exe,dll,scr,com,lnk | 聚焦最危险的文件类型 |
| 脚本排查 | js,ps1,vbs,bat,cmd,py,sh | 聚焦脚本类威胁 |
| 下载目录 | exe,dll,msi,js,ps1,vbs,bat,zip,rar,7z,lnk,scr | 覆盖下载常见威胁 |
| U 盘扫描 | exe,dll,scr,com,lnk,js,ps1,vbs,bat | 聚焦可执行和脚本威胁 |
| 项目目录 | py,sh,bat,ps1,js | 聚焦项目脚本安全 |

## 扩展名与实际类型不一致风险

某些扩展名可能被系统当作不同类型处理：

| 扩展名 | 系统可能当作 | 风险 |
|--------|-------------|------|
| .exe → .txt | 用户以为是文本，实际可执行 | 高 |
| .scr → .jpg | 用户以为是图片，实际是可执行 | 高 |
| .com → .doc | 用户以为是文档，实际可执行 | 高 |
| .lnk | 显示为目标文件名，实际指向任意路径 | 高 |
| .jar → .zip | 用户以为是压缩包，实际可执行 | 中 |

文件头签名检测可有效识别这类伪装。
