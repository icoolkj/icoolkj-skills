# 最终图片质量检查

读取最终交付图片而非只检查提示词或原图。每项记录 `pass`、`fail`、`unverified` 或 `not_applicable` 和证据/理由；不能把未检查当作通过。工具返回成功不等于质量合格。

## 必查项目

| 检查 ID | 检查内容与证据 |
|---|---|
| content | 对照用户输入和必保留清单逐项查遗漏；核对全部入图文案，不新增功能、数据、评价或联系方式。保留逐项位置与核对结果。 |
| visual | 实际看图，逐字检查中文笔画、标点、数字和单位，查看层级、可读性、边距、裁切和重叠；记录查看的具体版本。OCR 不能代替看图。 |
| dimensions | 记录最终图片实测宽高和格式，与目标像素/比例比较；比例正确不等于精确尺寸正确。 |
| access | 确认本地文件存在且可读，或实际附件/URL可访问；不得只填写预期输出路径。 |
| readability | 同时查看全尺寸及实际阅读宽度预览；数字传播默认 390 像素宽。核对手机号、价格条件、卡片正文等小字，记录阅读模式和实测字号。组件预检只是下限检测，不自动证明真实可读。 |
| assets | 记录素材源尺寸与最终使用尺寸、放大倍率，并查看最终清晰度。没有外部栅格素材时说明已检查且无该类素材；仅整图生成时检查真实图中细节，不能虚构图层尺寸。 |
| brand | 有品牌约束时核对品牌名、颜色、位置及原素材。严格 Logo 保真须有原素材合成记录并视觉核验；仅参考图重绘不能通过。 |
| edit_scope | 改图时对照修改前后：目标改动正确、必需保持区域未发生不允许变化；严格不变要求用适当差异检查辅助，不能仅凭提示词保证。 |
| qr | 要求二维码时核对目标与实际解码结果、静区和清晰度；无法解码验证则未验证。 |
| rights | 用户存在明确素材使用限制或授权疑点时核实对应使用范围。工具/字体许可需有实际依据；无问题时可不适用，不等同法律保证。 |
| print | 印刷用途核对用户/印厂指定物理尺寸、出血、分辨率与颜色/文件要求。缺少要求或能力时未验证，只能交数字版或草稿。 |
| direction | 与上一版导出图对比版式重复度；`reuse` 必须换方向，`related` 需确认同系列意图，证据写 similarity 与 verdict。无基线时标 unverified，不得声称已做防重复检查。 |
| html_export | `html_render` 路径必查：实际点击导出并确认文件生成；宽高 = 画布 × 倍率；按钮在海报外且不遮挡版心；页面无滚动；字体已加载；无 `background-clip: text`、`backdrop-filter`、`mix-blend-mode` 等导出不兼容属性。证据写导出文件名与实测尺寸，不能只写“脚本存在”。 | |

图片检查必含 content、visual、dimensions、access、readability、assets；其他项目根据任务适用，不能为通过而改为不适用。无 Logo 不等于无品牌约束。品牌系列对照同一版本的品牌配色、字体和页脚规则。`html_export` 只在 `html_render` 路径适用，证据记入布局报告，不加入 `delivery.json` 的固定检查集；未实测导出时该图最高只能为 `draft`。

确定性排版时将布局报告绑定到最终图片 SHA-256；改图后必须重新出报告。手机字号预检 fail 需实际修改版式解决；素材放大/zoom 阅读造成的 unverified 可在真实人工检查后补充证据，不得仅改状态。布局通过不代表中文无错字、事实准确或商用许可通过。

## 状态与修复

- 所有适用项通过且产物可访问，才设为 `ready`。
- 有可访问图但任一项失败或未验证，设为 `draft`，列出未通过项。
- 无产物且无法继续，设为 `blocked`；纯文字交付/无生图降级使用 `plan_only`。
- 单张成功不代表多张任务全部成功；逐张检查数量、内容、文件独立性。
- 修复优先针对失败项，仍需重新检查最终图；不遗漏修复引入的新错误。
- 自动尝试上限只以 SKILL.md 为准：每张每用户请求版本最多 3 次生成/编辑请求，含首次与失败/超时请求。达到上限后停止，明确草稿状态和替代方案。
- 无法看图或识别小字时如实标记 `unverified`，不得填写虚构的检查证据。
