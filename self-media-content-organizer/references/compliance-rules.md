# 合规规则

> NoteIntel references — 不虚构原则、引用规范与风险项识别

---

## 1. 不虚构原则

### 1.1 核心准则

**所有核心事实必须可在原文中找到对应内容。** 不补充原文中没有的信息、数据或结论。

### 1.2 虚构的判定

以下行为均属虚构，必须避免：

| 行为 | 示例 | 正确做法 |
|------|------|----------|
| 添加原文没有的数据 | 原文说"大幅增长"，提取为"增长50%" | 保留"大幅增长"，不编造具体数字 |
| 补充因果关联 | 原文只陈述现象，提取时添加原因 | 只提取现象，不补充原因 |
| 扩大适用范围 | 原文说"部分城市"，提取为"全国" | 保留"部分城市"的范围限定 |
| 合并不同信息 | 将原文不同段落的数据拼接为新结论 | 分别提取，不混源合并 |
| 生成原文未提及的结论 | 原文只提供数据，提取时添加结论 | 只提取数据，结论由选题角度推导 |

### 1.3 推断的标注

如需基于事实进行推断，必须：

- 明确标注为"推断"而非"事实"
- 注明推断依据（基于哪条事实推断）
- 不将推断混入核心事实列表

**格式**：
```
【推断】基于事实#3（2024年销量950万辆），推断2025年销量可能突破1200万辆
推断依据：按37%同比增长率推算
⚠️ 此为推断，非原文事实
```

## 2. 引用规范

### 2.1 引用标注格式

每条原文引用必须包含：

```
📎 原文引用："原文片段"
📍 来源位置：第X段，第Y句
```

### 2.2 引用完整性规则

- 引用内容必须与原文完全一致，不得修改任何字词
- 不截断句子——引用片段必须是完整的句子或完整的意思单元
- 如需省略中间部分，用`[...]`标注，且不改变原意
- 引用片段保留原文的标点符号

### 2.3 引用选择规则

- 优先引用包含核心数据的句子
- 引用片段应提供足够的上下文，让读者无需查看原文即可理解
- 同一事实在原文多处出现时，引用最完整的表述
- 不引用与事实无关的过渡性语句

## 3. 风险项识别

### 3.1 风险类型

| 风险类型 | 识别特征 | 处理方式 |
|----------|----------|----------|
| **敏感话题** | 涉及政治、宗教、种族、性别等敏感内容 | 标注风险，建议谨慎处理 |
| **未经证实的数据** | 原文标注"估计""大约""可能""预计"等限定词 | 保留限定词，标注为待证实 |
| **主观观点** | 含"我认为""应该""最好""必须"等主观判断 | 标注为观点，不作为事实 |
| **单一来源** | 数据仅来自一个来源，无交叉验证 | 标注为单一来源，建议补充验证 |
| **时效风险** | 数据有明显时效性，可能已过时 | 标注数据时间，提示时效性 |
| **利益相关** | 内容来源可能与某方利益相关 | 标注利益相关性，提示读者判断 |

### 3.2 风险标注格式

```
⚠️ 风险提示：
- 类型：未经证实的数据
- 内容："预计2025年销量突破1200万辆"
- 原文限定词："预计"
- 建议：此数据为预测值，非已确认事实，创作时需注明预测性质
```

### 3.3 风险项输出规则

- 风险提示模块：有风险项才输出，无则整块省略
- 每条风险项独立标注，不合并不同类型的风险
- 风险标注不影响事实提取，事实仍按原文内容提取，仅附加风险提示
- 不因风险而删除或修改事实内容

## 4. 合规自检清单

Agent 在完成信息提取和选题生成后，必须逐项自检：

| 检查项 | 标准 | 通过条件 |
|--------|------|----------|
| 事实可追溯 | 每条事实有原文定位 | 100%覆盖 |
| 数据不篡改 | 提取数据与原文一致 | 100%一致 |
| 不虚构 | 无原文中不存在的信息 | 零虚构 |
| 观点不混入事实 | 观点标注为观点 | 严格区分 |
| 引用完整 | 引用片段未截断、未修改 | 100%完整 |
| 风险项识别 | 敏感/未证实/主观内容已标注 | 应标尽标 |
| 选题有据 | 每条选题关联至少一条事实 | 100%关联 |
