# 信息提取指南

> NoteIntel references — 核心事实提取的领域知识

---

## 1. 什么算"独立事实"

独立事实是指原文中可以单独成立、不依赖其他上下文即可理解的信息单元。判断标准：

### 1.1 事实的构成要素

一条独立事实通常包含以下要素中的至少两项：

- **主体**：谁/什么（人、组织、产品、概念）
- **数据**：具体数字、百分比、金额、时间
- **关系**：主体之间的关联（因果、对比、趋势）
- **结论**：可验证的判断或发现

**示例**：
- ✅ "2024年中国新能源汽车销量达到950万辆，同比增长37%" — 主体+数据+关系
- ✅ "研究显示，每天步行30分钟可降低心血管疾病风险20%" — 主体+数据+结论
- ❌ "新能源汽车很重要" — 仅有主体，无数据支撑，属观点而非事实

### 1.2 事实与观点的区分

| 类型 | 特征 | 处理方式 |
|------|------|----------|
| 事实 | 包含具体数据、可验证、有明确主体 | 提取为核心事实 |
| 观点 | 主观判断、无数据支撑、含"我认为/应该/最好" | 标注为观点，不作为事实提取 |
| 推断 | 基于事实的延伸判断，原文有逻辑推导过程 | 标注为推断，注明推导依据 |

### 1.3 事实去重规则

- 同一数据在不同段落重复出现，只提取一次，注明所有出现位置
- 同一事实用不同表述重复，合并为一条，保留最完整的表述
- 互补事实（如"增长37%"和"从690万增至950万"）合并为一条

## 2. 数据提取规则

### 2.1 数据类型识别

| 数据类型 | 识别特征 | 提取要求 |
|----------|----------|----------|
| 绝对数值 | 具体数字+单位（950万辆、120亿元） | 保留原始数字和单位 |
| 相对数值 | 百分比、倍数（增长37%、翻了3倍） | 保留百分比/倍数+基准值（如有） |
| 时间数据 | 日期、时间段（2024年、近三年） | 保留时间范围 |
| 排名数据 | 第X、最大/最小、领先/落后 | 保留排名+对比范围 |
| 对比数据 | A vs B、高于/低于/相当于 | 保留对比双方和差异值 |

### 2.2 数据精度保留

- 不四舍五入、不简化原始数据
- 如原文说"约950万辆"，提取时保留"约"字
- 如原文说"950.3万辆"，提取时保留完整精度

## 3. 原文定位方法

每条提取的核心事实必须标注原文位置，确保可追溯。

### 3.1 定位标注格式

```
【事实内容】
📍 原文定位：第X段 / 第X-Y句
📎 原文引用："原文对应片段"
```

### 3.2 定位规则

- 段落编号从1开始，按原文自然段落计数
- 句子编号从1开始，按段落内句号/问号/叹号分隔计数
- 引用片段保留原文原文，不做任何修改
- 如事实散布在多个段落，标注所有相关位置

### 3.3 引用片段长度

- 引用片段应包含事实的完整上下文，通常1-3句
- 不截断句子，保持语义完整
- 如原文过长，可标注关键句+省略号

---

## 4. 提取质量标准

### 4.1 必须满足

- 每条事实可在原文中找到对应内容（不虚构）
- 每条事实有原文定位标注（可追溯）
- 数据精度与原文一致（不篡改）
- 事实与观点严格区分（不混淆）

### 4.2 应该避免

- 提取原文中没有的信息（不补充）
- 将主观观点作为事实提取（不混淆）
- 省略数据的限定条件（如"约""预计""初步"）
- 将不同来源的数据合并（不混源）

### 4.3 提取优先级

当配额有限时，按以下优先级提取：

1. 含具体数据的核心事实（最高优先）
2. 含因果关系的事实
3. 含对比/排名的事实
4. 含趋势/变化的事实
5. 描述性事实（最低优先）
