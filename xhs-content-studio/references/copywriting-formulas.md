# Xiaohongshu & Multi-Platform Copywriting Formulas · 小红书与多平台爆款文案公式库 (Bilingual Guide)

## 1. Five High-CTR Xiaohongshu Title Formulas · 5 大高点击率标题公式 (Strictly ≤ 20 Chinese Characters)

Xiaohongshu mobile feed truncates titles beyond 20 Chinese characters. Always generate 5 distinct options covering these angles:
小红书双列瀑布流标题严格限制在 **20 个汉字以内**。每次生成必须覆盖以下 5 种高点击率切入角度：

1. **Numeric Pain-Point Hook (数字痛点型)**:
   - *Formula*: `[高频动作/次数] + [核心对象] + [反转追问/揭秘]`
   - *Bilingual Example*: `填了100遍的AI接口，到底是个啥` (16 chars) / `熬夜3天整理的工具开发避坑指南` (15 chars)
2. **Target Audience Callout (受众点名型)**:
   - *Formula*: `[精准人群] + [千万别/停止某低效行为] + [替代解法]`
   - *Bilingual Example*: `开发者别填错BaseURL，小心404` (17 chars) / `所有程序员！别再手写重复提示词了` (16 chars)
3. **Before/After Efficiency Contrast (效率反差型)**:
   - *Formula*: `从 [旧痛点状态] 到 [新高效结果]，只改了 [1个关键动作]`
   - *Bilingual Example*: `从天天404到一把过，就改了个前缀` (16 chars) / `从2小时到3分钟，长文拆成多张干货图` (17 chars)
4. **Nanny-Level Checklist / Template (保姆级清单型)**:
   - *Formula*: `[领域关键词] + 保姆级清单/全攻略 + (附 [可直接抄的资产])`
   - *Bilingual Example*: `AI接口后缀避坑清单(附场景选择图)` (18 chars) / `内容工作流开发清单(附双端发布口令)` (18 chars)
5. **Hands-On Tear-Down / Secret Reveal (实测拆解揭秘型)**:
   - *Formula*: `把 [复杂概念] 拆开讲透，[X]分钟看懂`
   - *Bilingual Example*: `把AI接口路径拆开讲透，3分钟看懂` (16 chars) / `实测内容工作流：10分钟搭出可复用模板` (18 chars)

## 2. 3:4 Carousel Card Information Density Rules · 3:4 图文卡片信息密度与中英双语规范

Mobile readers spend **1.5 to 3 seconds** per slide. Enforce strict density caps and bilingual visual hierarchy:
移动端读者单张卡片停留时间仅 **1.5–3 秒**，必须严格控制字数并采用中英双语视觉锚点：

| Card Index (页码) | Narrative Role (叙事定位) | Bilingual Eyebrow Token (中英双语眉题示例) | Max Body Copy (单页字数上限) |
| :--- | :--- | :--- | :--- |
| **P1 (Cover)** | 3-Second Visual Hook (封面大字报) | `COVER · 01 / 主题与阅读收益` | Headline ≤ 14 chars + Subtitle ≤ 18 chars |
| **P2…PN-2 (Facts)** | Source-grounded fact groups (来源事实组) | `FACT · 02 / 核心事实` | 每页 1–3 条同主题事实，保留 ID 与来源 |
| **PN-1 (Boundary)** | Boundary & verification (边界与核查) | `BOUNDARY / 发布前核对` | 限定词、风险、争议和待核查问题 |
| **PN (Checklist)** | Recap & CTA (省流复盘与互动) | `CHECKLIST / 完结自检` | 来源提示、核对项和评论问题 |

## 3. Compliance & Traffic-Throttling Filter · 广告法违禁词与平台限流词替换表

Never output absolute superlatives (极限词) or single-character `"最 + 形容词"` constructions that trigger algorithmic throttling:

| High-Risk / Prohibited Term (高危限流/违禁词) | Safe, High-Conversion Replacement (安全高转化替代词) |
| :--- | :--- |
| `国家级` / `世界级` / `宇宙级` | `行业标杆级` / `高标准` / `专业级` |
| `全网第一` / `全网首家` / `独一无二` | `超实用` / `实测高赞` / `少见但好用` |
| `最牛` / `最佳` / `顶级` / `终极` / `完美` | `亲测好用` / `核心必看` / `高阶实操` / `完成度极高` |
| `最成熟` / `最好` / `最强` / `最快` (Single `最` + Adj) | `极为成熟` / `尤为出色` / `表现亮眼` / `响应迅速` |
| `100%有效` / `包过` / `稳赚不赔` / `零风险` | `大幅少走弯路` / `显著提升效率` / `避坑实测` |
| `加微` / `VX` / `公众号搜` / `私信领钱` (Hard Drainage) | `评论区交流` / `看置顶笔记` / `收藏慢慢看` |

## 4. Multi-Platform Adaptation Matrix · 一鱼多吃跨平台改写规范

- **WeChat Moments (微信朋友圈防折叠版)**:
  - Strictly **3 to 5 lines**, total length **≤ 110 characters**. WeChat collapses posts exceeding 6 lines into a folded "全文" link, cutting read-through rates by 60%+.
- **Jike / Developer Community (即刻 / 开发者社区 Builder 版)**:
  - Open with `【Builder 实操笔记 / Dev Log】`, list 4–5 bulleted architectural takeaways, and invite peer engineers to share edge cases.
- **WeChat Official Account Lead-In (微信公众号 / 知识库导读摘要)**:
  - 120–160 characters in structured editorial prose (`导读摘要 / Executive Summary`) suitable for top-of-article callout boxes.
- **30-Second Short-Video / Pitch Script (30秒短视频与路演口播稿)**:
  - Divided into 4 exact timecodes: `[00:00-00:03 Golden Hook]`, `[00:03-00:10 Pain Point]`, `[00:10-00:25 3-Step Demo]`, `[00:25-00:30 CTA]`.
