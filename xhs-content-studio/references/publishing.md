# 小红书发布流程与安全边界

本 Skill 可以准备小红书发布包，也可以在用户授权后使用浏览器辅助填写发布页面，但公开发布属于外部高影响操作，最终提交必须获得用户明确确认。

## 发布包

发布包至少包括：

- 最终标题
- 正文和话题标签
- 按 P1–PN 排序的 PNG 图片；N 由文章事实和卡片页数决定
- 来源与免责声明
- `content-pack.json` 校验结果
- 图片 `approved` 状态和验收记录

## 浏览器流程

1. 打开小红书创作页面。
2. 检查当前账号和发布入口是否正确。
3. 上传 PNG，确认顺序、数量、比例和预览效果。
4. 填写标题、正文和话题。
5. 停在最终发布按钮前，向用户展示完整 payload：标题、正文、图片数量、话题和可见范围。
6. 只有用户明确确认后，才点击最终发布。

登录、短信验证码、图形验证码、风控挑战和账号安全设置由用户完成，不绕过平台验证。若无法确认当前账号、可见范围或发布内容，停在草稿/预览状态并说明原因。
