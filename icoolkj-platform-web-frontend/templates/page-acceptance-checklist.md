# 页面验收清单

## 信息架构

- [ ] 一级菜单、二级菜单和页面内容职责清楚
- [ ] 当前路由直达和刷新后仍正确激活
- [ ] 布局选择符合任务，不为填充空间强行增加列
- [ ] 每个可见按钮都对应真实路由、API 或本地状态行为

## 认证与范围

- [ ] 当前用户上下文已加载并正确显示
- [ ] JWT 当前组织与页面数据范围没有混用
- [ ] 组织切换会清理/冻结旧数据并阻止过期响应覆盖
- [ ] 页面、按钮和数据范围权限与后端契约一致

## 状态与错误

- [ ] 首次加载、刷新、提交和行操作状态相互独立
- [ ] 异步操作防重复，失败可重试且保留输入
- [ ] 401、403、404、409、422、超时和网络错误有合理反馈
- [ ] 空数据、无匹配、无权限、加载失败和未接入状态有区别
- [ ] 未保存修改在切换对象、组织或页面前有提示

## 视觉与可访问性

- [ ] 1440px、1024px、768px、390px 下无页面级横向溢出
- [ ] 主操作、组织范围和标题在窄屏仍可达
- [ ] 键盘焦点、Tab、Enter/Space、Esc 流程可用
- [ ] 图标按钮具备 aria-label 和 tooltip
- [ ] reduced motion 下仍能理解 loading、成功和失败结果

## 工程验证

- [ ] 前端类型检查和生产构建通过
- [ ] 相关后端权限/组织范围测试通过
- [ ] 记录了可复核的截图、录屏或测试证据
