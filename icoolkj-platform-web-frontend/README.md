# icoolkj-platform Web 前端设计

用于 icoolkj-platform 多租户 Web 应用的前端信息架构、菜单布局、页面交互和响应式验收。

覆盖：

- 一级菜单、二级菜单和单栏/左右/左中右布局决策
- 组织范围上下文、路由元数据和权限交互
- 表格、表单、弹窗、按钮状态和重复提交保护
- 加载、空数据、无权限、冲突、失败和恢复状态
- 宽屏、中等宽度、平板、移动端和键盘验收

后端认证授权使用 `icoolkj-platform-web-backend`；框架表结构、PostgreSQL DDL 和迁移使用 `icoolkj-platform-web-database`。
