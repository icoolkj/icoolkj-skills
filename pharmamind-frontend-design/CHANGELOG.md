# Changelog

## 1.5.0 - 2026-11-19

- 将用户提供的 33 张系统表定义为所有该技能项目必须完整初始化的基线。
- 新增 PostgreSQL/pgvector 适配 DDL，覆盖 455 个字段、索引、约束、注释和更新时间触发器。
- 更正数据库命名约定：仅表名使用 `icoolkj_` 前缀；字段、索引、约束、触发器和函数均不加此前缀。
- 明确应用业务表只能在系统基线之上扩展；不再重复建设用户、租户和 RBAC 主数据。
- 补充版本化迁移、现有数据兼容、排序规则差异以及源 DDL 无外键/种子数据的边界。
- 版本 1.4.0 -> 1.5.0。

## 1.4.0 - 2026-11-19

- 新增 `icoolkj_` 数据库表命名空间；字段、索引和具名约束使用常规名称。
- 明确 ORM 属性/API 字段与物理数据库名称分离，保持外部契约兼容。
- 补充 MySQL DDL 作为业务结构参考、适配 PharmaMind PostgreSQL/pgvector 的规则。
- 补充既有数据库重命名的迁移与数据保护要求，并澄清前缀不是版权证明。
- 版本 1.3.0 -> 1.4.0。

## 1.3.0 - 2026-11-19

- 技能从页面视觉与按钮规范扩展为前端工程与交互设计规范。
- 新增认证上下文、JWT 当前组织、页面数据范围和 RBAC 菜单的对齐要求。
- 新增 API 权限契约审查、错误分类、请求竞态和异步状态模型。
- 新增表格规模化、分页筛选、字段级校验和空/无权/失败状态规范。
- 新增宽屏、中等宽度、移动端、键盘和减少动态效果的视觉验收要求。
- 新增路由元数据、权限矩阵和页面验收模板。
- 版本 1.2.0 -> 1.3.0。
