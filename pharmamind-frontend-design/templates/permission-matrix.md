# 权限矩阵

| Route / 页面 | 页面查看权限 | 数据范围 | 主操作 | API 方法 | API 权限依赖 | 失败/冲突 | 可恢复性 |
|---|---|---|---|---|---|---|---|
| `/example` | `example:read` | 当前组织及授权下级 | 示例操作 | `POST /...` | `example:write` | 403 / 409 / 422 | 可重试 |

## 使用规则

- 页面权限、按钮权限和数据范围分别填写。
- API 权限依赖必须以后端实际依赖为准，不按按钮文案猜测。
- 每个主操作都填写成功后数据如何刷新，以及失败后用户如何恢复。
- 没有 API、权限依赖或组织校验的行不能进入可用页面。
