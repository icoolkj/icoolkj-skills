# 排版风格规范

## standard（标准风格）

适用场景：通用文档、技术文档、日常报告。

| 元素 | 设置 |
|------|------|
| 页面 | A4 (210mm × 297mm)，上下边距 2.54cm，左右边距 3.18cm |
| 正文 | 宋体 12pt，行距 1.5，段前 0pt，段后 6pt |
| H1 | 黑体 22pt，段前 24pt，段后 12pt，加粗 |
| H2 | 黑体 18pt，段前 18pt，段后 8pt，加粗 |
| H3 | 黑体 16pt，段前 14pt，段后 6pt，加粗 |
| H4~H6 | 黑体 14~11pt，段前 12~8pt，段后 4pt |
| 引用 | 仿宋 12pt，斜体，左缩进 1cm，灰色竖线 |
| 代码块 | Consolas 10pt，灰色背景 #F0F0F0，左缩进 0.5cm |
| 行内代码 | Consolas 11pt，灰色背景 |
| 列表 | 宋体 12pt，行距 1.5，缩进 0.75cm |
| 表格 | 宋体 11pt，表头加粗 + 灰色背景 #E0E0E0 |
| 链接 | 蓝色 #0000FF + 下划线 |
| 图片 | 居中，最大宽度 15cm |

## clean（简约风格）

适用场景：屏幕阅读、在线文档、内部协作。

| 元素 | 设置 |
|------|------|
| 页面 | A4，上下边距 2cm，左右边距 2.5cm |
| 正文 | Microsoft YaHei 11pt，行距 1.6，段前 0pt，段后 8pt |
| H1 | Microsoft YaHei 20pt，段前 20pt，段后 10pt |
| H2 | Microsoft YaHei 16pt，段前 16pt，段后 8pt |
| H3 | Microsoft YaHei 14pt，段前 12pt，段后 6pt |
| 引用 | Microsoft YaHei 11pt，左缩进 0.8cm，灰色竖线 |
| 代码块 | Consolas 10pt，浅灰背景 #F5F5F5 |
| 表格 | Microsoft YaHei 10pt，表头浅蓝背景 #E8F0FE |
| 链接 | 蓝色 #1A73E8 |
| 图片 | 居中，最大宽度 16cm |

## formal（正式风格）

适用场景：正式报告、合同、学术论文、政府文件。

| 元素 | 设置 |
|------|------|
| 页面 | A4，上下边距 2.54cm，左右边距 3.18cm |
| 页眉 | 文档标题，宋体 9pt，居中 |
| 页脚 | 页码，宋体 9pt，居中 |
| 正文 | 仿宋 12pt（GB2312），行距 1.5，段前 0pt，段后 6pt，首行缩进 2字符 |
| H1 | 黑体 22pt，段前 24pt，段后 12pt，居中 |
| H2 | 黑体 18pt，段前 18pt，段后 8pt |
| H3 | 黑体 16pt，段前 14pt，段后 6pt |
| 引用 | 楷体 12pt，左缩进 1.2cm |
| 代码块 | Courier New 10pt，灰色背景 |
| 表格 | 仿宋 11pt，表头黑体 + 灰色背景 |
| 链接 | 黑色 + 下划线（正式文档不使用彩色链接） |
| 图片 | 居中，图注（图1：xxx）仿宋 10pt |

## blog（博客风格）

适用场景：博客文章、在线发布、轻量级文档。

| 元素 | 设置 |
|------|------|
| 页面 | A4，上下边距 1.5cm，左右边距 2cm |
| 正文 | Microsoft YaHei 12pt，行距 1.8，段前 0pt，段后 12pt |
| H1 | Microsoft YaHei 24pt，段前 24pt，段后 12pt |
| H2 | Microsoft YaHei 20pt，段前 20pt，段后 10pt，底部边框线 |
| H3 | Microsoft YaHei 16pt，段前 16pt，段后 8pt |
| 引用 | Microsoft YaHei 12pt，左缩进 0.5cm，左侧粗竖线 #333333 |
| 代码块 | Consolas 11pt，深色背景 #282C34，浅色文字 #ABB2BF |
| 行内代码 | Consolas 12pt，浅灰背景 |
| 表格 | Microsoft YaHei 11pt，表头加粗 |
| 链接 | 蓝色 #0066CC + 下划线 |
| 图片 | 居中，最大宽度 17cm，图注居中 |

## 风格选择建议

| 用户场景 | 推荐风格 |
|----------|----------|
| 技术文档、API 文档 | standard |
| 内部协作、在线阅读 | clean |
| 正式报告、合同、论文 | formal |
| 博客、轻量级文档 | blog |
| 用户未指定 | standard（默认） |
