# 质量检查清单

生成海报后（SKILL.md 第 8 步）逐项检查。任何一项不通过都要处理后才交付。

## 1. 文字准确性

- [ ] 主标题、副标题每个字与整理后的文案完全一致，无错字、漏字、乱码
- [ ] 卖点短句文字正确
- [ ] 底部标语文字正确
- [ ] 数字、价格、日期、单位（如 %、GB、元）准确无误
- [ ] 中文笔画完整、无变形、无伪文字（看起来像字但读不出来的乱码）

## 2. 品牌一致性

- [ ] Logo 未被重绘、变形、变色（有参考图传入时）
- [ ] 品牌名称与用户提供的完全一致
- [ ] 主色调与品牌色或确认过的配色方案一致
- [ ] 用户指定的品牌要求（位置、配色限制）已遵守

## 3. 布局与层级

- [ ] 比例与要求一致（如 3:4）
- [ ] 主标题是画面中最醒目的文字
- [ ] 信息层级清晰：主标题 > 副标题 > 卖点 > 标语
- [ ] 画面留白充足，无文字贴边、无元素重叠
- [ ] 视线动线合理：先标题 → 主视觉 → 卖点 → 行动信息

## 4. 可读性

- [ ] 文字与背景对比度足够（深底浅字或浅底深字）
- [ ] 最小层级文字仍可辨认
- [ ] 文字未被背景纹理、图形干扰

## 5. 内容准确性

- [ ] 所有功能描述、数据、事实与用户输入一致，无虚构
- [ ] 无凭空出现的品牌、人物、奖项、评价
- [ ] 多张海报时每张内容各自正确、未混排

## 6. 问题处理

| 问题严重度 | 判断 | 处理 |
|---|---|---|
| 轻微 | 个别错字、局部小偏差 | 带明确修改意见直接重新生成一次 |
| 中等 | 多处文字错误、层级不清 | 收紧文字量与排版描述后重新生成 |
| 结构性 | 版式/配色/风格方向不对、比例错误 | 先向用户说明发现的问题与调整方向，确认后再重做 |

同一问题连续重新生成 2 次仍未解决时，停止重试，向用户说明该问题的常见原因（如中文长句渲染弱），并提供替代方案（精简文字 / 文案后期排版 / 更换风格词）。
