# 提示词与修改指南

## 1. 生成提示词结构

每张独立编写以下内容，并用实际任务资料填全后执行：

1. 用途、画面比例、目标像素宽高（若指定）、视觉目标。
2. 风格、背景、品牌色、留白和主视觉，不机械套用行业配色。
3. 版式和文字层级：逐字列出入图标题、正文、条件、数字与单位，标明位置。
4. 素材角色映射：哪张是原版 Logo、哪张是产品图、哪张仅为风格参考、哪张是编辑底图。
5. 必须保留的视觉事实、禁止新增的内容、不能改变的区域。
6. 合成计划：哪些元素由后续确定性合成加入；仅预留空间，不生成“Logo占位”等字样。
7. 清晰、易读、无无关水印和多余文字等质量要求。

工具不支持独立负面提示词时写入正向自然语言；不得臆造参数。纯文本提示词可迁移复用，但模型和平台的素材输入方式、参数需分别适配，不承诺任意工具直接获得同样结果。

## 2. 中文与必保留内容

- 将必保留清单映射到最终文案：ID、原文、对应位置。未获用户修改指示时不得删掉价格条件、型号、单位、限制条款。
- 主标题约 12 字、卖点约 10 字仅作建议；禁止为凑字数改品牌名称、删技术参数或将繁体/生僻品牌字替换成常用字。
- 卖点按来源实际数量提炼，不为满足模板发明第三条。可选标语、联系方式无资料时省略，不填伪数据。
- 文字较长或必须精确时优先背景生成后排字，能力不足则交待排版草稿。不得通过不断重生逃避文字问题。
- 对实际输出逐字核对；“所有中文必须准确”只是生成要求，不是验收证据。

## 3. 品牌和素材

严格原样 Logo 用原素材合成，不能以参考图生成代替。品牌图只用于指定品牌，不与风格参考图混淆。参考图提取色彩、构图与质感；不复制其品牌、文案、签名、水印或完整创作。

原二维码或精确商品外观交由保真流程处理。没有素材不虚构真实产品界面或扫码入口。

确定性排版路径下，为主视觉单独写提示词：仅背景、插画、真实素材允许的视觉变化和留白，不要求模型绘制中文标题、微型表格、虚假界面、Logo 或二维码。完整文案与原图位置放进排版配方。示意流程用实际文字和编号/清晰单向连接表达，按产品资料核对顺序；样例数据需标“示意”。

## 4. 修改提示词

先定位底图及版本，建立变更清单：旧值、新值、修改位置、保持区域。用户明确修改的数据同步更新必保留清单。

| 请求 | 优先执行 |
|---|---|
| 改价格/文字，其他不动 | 原排字层精确修改；否则底图局部编辑并检查保持区域 |
| 调整 Logo 位置 | 重新合成原 Logo；不让模型重绘 |
| 改颜色/风格 | 基于底图和保留要求调整；整体风格改变需检查全部内容 |
| 文字拥挤 | 调整布局或排字，先保留全部必需信息 |
| 多张系列图 | 共用品牌约束，各张独立文案、独立提示词、独立输出 |

只有整图生成能力时说明其余区域也可能变化；用户要求严格不变则不能用整图重生宣称满足。新版本不覆盖原图，修复后检查整张图以捕获新错误。所有重试遵循 SKILL.md 的统一总次数上限。
