# 图像生成提示词编写指南

提示词编写阶段（SKILL.md 第 6 步）和迭代修改时查阅本文件。

## 1. 提示词结构模板

按以下顺序组织提示词，各段用自然语句连接：

```text
[1. 画面类型与比例] 一张竖版宣传海报，3:4 比例
[2. 整体风格] 现代简约商业风格 / 科技感 / 国潮 …
[3. 背景与配色] 深蓝色渐变背景，主色 #0B1F3A，强调色 #2F6FED
[4. 主视觉] 画面中上部为……（产品图 / 插画 / 图形的描述）
[5. 文字内容] 逐字列出所有文字及其位置、层级：
  - 顶部居中大标题文字"××××"
  - 大标题下方副标题文字"××××"
  - 中部三个卖点，图标配文字："×××""×××""×××"
  - 底部标语文字"××××"
  - 左上角放置品牌 Logo
[6. 排版要求] 层级分明、留白充足、文字清晰可读
[7. 质量词] 高分辨率、专业平面设计、商业海报质感
```

## 2. 关键规则

### 2.1 文字逐字写入

海报中出现的每一个字都必须在提示词中逐字写明，包括标点；不得写"此处放标题"之类的占位描述。生成后按质量检查清单核对每个字。

### 2.2 中文渲染策略

中文是当前图像生成模型的弱项，尽量提高成功率：

- 文字总量精简：主标题 ≤ 12 字，卖点每条 ≤ 10 字，全海报 ≤ 60 字
- 常用词优先；避免生僻字、繁体、长句入图
- 明确声明"海报中的所有中文文字必须准确清晰、笔画完整、无变形无乱码"
- 用户坚持长文案时：建议主视觉生成 + 文案后期排版（输出设计方案时说明这一建议）

### 2.3 Logo 处理

- 工具支持参考图/图生图：把 Logo 作为参考图传入，并在提示词中注明"左上角保留传入的品牌 Logo，保持原样不变形不改色"
- 工具不支持参考图：提示词中只留出 Logo 占位区域（"左上角预留品牌标识位置"），交付时向用户说明 Logo 需后期合成，或建议提供白底 Logo 区域

### 2.4 参考图风格迁移

用户给了参考海报时，把风格描述转写为提示词词汇（配色、构图、光影、插画/摄影、字体感觉），不描述参考图中的具体物体与文字。

## 3. 负面提示词模板

工具支持负面提示词时附带：

```text
乱码文字、错别字、变形的文字、扭曲的Logo、水印、签名、
模糊、低分辨率、杂乱元素、文字贴边、画面拥挤
```

不支持时，在正向提示词末尾追加一句："画面干净整洁，无乱码文字，无水印，所有文字清晰可读。"

## 4. 迭代修改的提示词调整

用户反馈 → 提示词调整对照：

| 反馈 | 调整位置 |
|---|---|
| "换个风格，更科技感" | 第 2 段风格词 + 第 3 段配色 |
| "标题太大了/太小了" | 第 5 段中标题的字号层级描述（"超大号主标题" / "适度大号"） |
| "换个颜色" | 第 3 段配色描述 |
| "卖点改成……" | 第 5 段对应文字逐字替换 |
| "画面太空/太挤" | 第 6 段排版要求（增加留白 / 收紧布局） |
| "参考这张图的感觉" | 把新参考图风格词并入第 2、3 段 |

只改用户指出的部分，其余段落原样保留，避免一次重写导致画面失控。

## 5. 多张海报

用户要求多张时：每张独立编写完整提示词（各自的比例、版式、文字），分别调用生成，禁止把多张内容描述进同一个提示词或拼接图片。
