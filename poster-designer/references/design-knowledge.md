# 海报设计知识库（视觉策划用）

视觉策划阶段（SKILL.md 第 5 步）按需查阅本文件，用于确定版式布局、配色方案与视觉风格。

## 1. 海报比例选择

| 比例 | 适用场景 |
|---|---|
| 3:4 竖版 | 默认方案；社交媒体、朋友圈、印刷易拉宝的通用比例 |
| 9:16 竖版 | 手机全屏、短视频封面、 Stories |
| 1:1 方版 | 社交媒体信息流、电商主图 |
| 16:9 横版 | 网站横幅、PPT 封面、会议背景 |
| 2:1 / 横长 | 公众号头图、Banner |

用户指定尺寸时优先用户要求；未指定时用 3:4。

## 2. 版式布局模式

按卖点数量和信息密度选择：

**A. 居中主视觉型**（卖点 ≤3，信息少）
- 顶部：Logo + 品牌名
- 上部 1/3：主标题 + 副标题
- 中部：产品图或主视觉
- 下部：卖点横排 / 标语 + 行动信息
- 适合：品牌氛围海报、单卖点活动海报

**B. 上下分层型**（卖点 3–5，信息中等）
- 顶部：Logo、主标题、副标题
- 中部：主视觉（产品图 / 插画 / 抽象图形）
- 中下部：卖点区，2×2 或 1×4 图标网格
- 底部：标语、行动号召、联系方式
- 适合：产品宣传、功能介绍

**C. 左右分栏型**（横版为主）
- 左栏（约 40%）：标题、副标题、卖点列表
- 右栏：产品图或主视觉
- 适合：16:9 横版、软件产品海报

**D. 全幅背景型**（氛围优先，文字少）
- 全幅场景图 / 渐变背景
- 大字主标题叠加居中或左上
- 角落放 Logo 与一句标语
- 适合：品牌宣传、活动预热

## 3. 配色方案库

结构一律为：主色（背景/大块面）+ 辅助色（图形、分区）+ 强调色（标题、按钮、价格）。

| 行业/调性 | 推荐组合 |
|---|---|
| 科技 / 软件 | 深蓝 #0B1F3A + 电光蓝 #2F6FED + 青色点缀 #23D3C4 |
| 商务 / 企业 | 藏蓝 #16305C + 灰白 #F2F4F8 + 金色 #C9A45C |
| 电商 / 促销 | 正红 #E0281E + 橙黄 #FF8A00 + 白底 |
| 教育 / 知识 | 靛蓝 #2B4ACB + 浅米 #F7F4EC + 珊瑚橙 #FF7A45 |
| 健康 / 医疗 | 青绿 #0E9E8E + 白 #FFFFFF + 浅绿 #DFF3EF |
| 金融 / 理财 | 深蓝 #0A2A5E + 银灰 #E8ECF2 + 亮金 #D8B15C |
| 餐饮 / 食品 | 暖橙 #F26A1B + 奶油白 #FFF6EA + 深棕 #4A2C17 |
| 美妆 / 时尚 | 裸粉 #F3C6C6 + 香槟金 #D9B779 + 深灰 #2B2B2B |
| 环保 / 农业 | 草绿 #3C9E44 + 米白 #F6F3E7 + 泥土棕 #8C6239 |
| 文创 / 艺术 | 墨黑 #1A1A1A + 宣纸白 #F5F1E6 + 朱红 #C03F2B |

无品牌色时按上表推导；有品牌色时以品牌色为主色，强调色从主色的邻近色或互补色中取。

## 4. 视觉风格库

| 风格 | 特征 | 适用 |
|---|---|---|
| 现代简约 | 大留白、几何图形、克制配色 | 软件、商务（默认风格） |
| 科技感 | 深色底、光效、线条网络、粒子 | 互联网、AI、硬件 |
| 3D 质感 | 立体产品渲染、柔和光影 | 产品发布、硬件 |
| 扁平插画风 | 矢量插画、明快色块 | 教育、互联网活动 |
| 手绘插画风 | 温暖笔触、有机形状 | 文创、餐饮、生活服务 |
| 摄影实景 | 真实场景照片、自然光影 | 餐饮、地产、旅游 |
| 国潮 | 传统纹样、朱红金色、书法感 | 文化、节庆、国货品牌 |
| 大字报促销 | 高饱和色块、超大字号、价格醒目 | 电商促销、门店活动 |

## 5. 文字层级规范

- 主标题：占画面宽度 60% 以上，字重最粗，位于视觉焦点区
- 副标题：主标题字号的 40%–50%，与主标题间距为其字高的 0.5–1 倍
- 卖点文案：短句 + 图标，字号 ≥ 副标题的 60%，行间距宽松
- 底部标语/联系信息：最小层级，但对比度仍需保证可读
- 全海报层级不超过 4 级；文字总量控制在 60 字以内（不含必要参数）

## 6. 图标与功能展示区

- 卖点区采用"图标 + 6 字以内短文案"网格：2×2、1×3 或 1×4
- 图标风格与整体风格一致（线性图标配简约风，面性图标配插画风）
- 每个卖点之间留出明显间隔，禁止文字贴边
