# 海报设计知识库（视觉策划用）

视觉策划阶段按需查阅本文件，用于确定版式布局、配色方案与视觉风格。

## 1. 海报比例选择

| 比例 | 适用场景 |
|---|---|
| 3:4 竖版 | 默认数字传播方案；印刷及易拉宝按实际成品尺寸确定，不能套用此比例 |
| 9:16 竖版 | 手机全屏、短视频封面、 Stories |
| 1:1 方版 | 社交媒体信息流、电商主图 |
| 16:9 横版 | 网站横幅、PPT 封面、会议背景 |
| 2:1 / 横长 | 公众号头图、Banner |

用户指定尺寸时优先用户要求；未指定时用 3:4。

## 2. 版式布局模式

按卖点数量和信息密度选择：

**A. 居中主视觉型**（卖点 ≤3，信息少）
- 顶部：Logo + 品牌名
- 上部 1/3：主标题 + 副标题
- 中部：产品图或主视觉
- 下部：卖点横排 / 标语 + 行动信息
- 适合：品牌氛围海报、单卖点活动海报

**B. 上下分层型**（卖点 3–5，信息中等）
- 顶部：Logo、主标题、副标题
- 中部：主视觉（产品图 / 插画 / 抽象图形）
- 中下部：卖点区，2×2 或 1×4 图标网格
- 底部：标语、行动号召、联系方式
- 适合：产品宣传、功能介绍

**C. 左右分栏型**（横版为主）
- 左栏（约 40%）：标题、副标题、卖点列表
- 右栏：产品图或主视觉
- 适合：16:9 横版、软件产品海报

**D. 全幅背景型**（氛围优先，文字少）
- 全幅场景图 / 渐变背景
- 大字主标题叠加居中或左上
- 角落放 Logo 与一句标语
- 适合：品牌宣传、活动预热

## 3. 配色方案库

按品牌和传播目标选色；下表仅提供灵感，不是行业强制规范。可采用主色＋辅助色＋强调色，也可采用单色或品牌既有色系。活动以时间地点和行动信息为重，产品以真实卖点为重，品牌氛围以识别度为重。

| 行业/调性 | 推荐组合 |
|---|---|
| 科技 / 软件 | 深蓝 #0B1F3A + 电光蓝 #2F6FED + 青色点缀 #23D3C4 |
| 商务 / 企业 | 藏蓝 #16305C + 灰白 #F2F4F8 + 金色 #C9A45C |
| 电商 / 促销 | 正红 #E0281E + 橙黄 #FF8A00 + 白底 |
| 教育 / 知识 | 靛蓝 #2B4ACB + 浅米 #F7F4EC + 珊瑚橙 #FF7A45 |
| 健康 / 医疗 | 青绿 #0E9E8E + 白 #FFFFFF + 浅绿 #DFF3EF |
| 金融 / 理财 | 深蓝 #0A2A5E + 银灰 #E8ECF2 + 亮金 #D8B15C |
| 餐饮 / 食品 | 暖橙 #F26A1B + 奶油白 #FFF6EA + 深棕 #4A2C17 |
| 美妆 / 时尚 | 裸粉 #F3C6C6 + 香槟金 #D9B779 + 深灰 #2B2B2B |
| 环保 / 农业 | 草绿 #3C9E44 + 米白 #F6F3E7 + 泥土棕 #8C6239 |
| 文创 / 艺术 | 墨黑 #1A1A1A + 宣纸白 #F5F1E6 + 朱红 #C03F2B |

无品牌色时按上表推导；有品牌色时以品牌色为主色，强调色从主色的邻近色或互补色中取。

## 4. 视觉风格库

| 风格 | 特征 | 适用 |
|---|---|---|
| 现代简约 | 大留白、几何图形、克制配色 | 软件、商务（默认风格） |
| 科技感 | 深色底、光效、线条网络、粒子 | 互联网、AI、硬件 |
| 3D 质感 | 立体产品渲染、柔和光影 | 产品发布、硬件 |
| 扁平插画风 | 矢量插画、明快色块 | 教育、互联网活动 |
| 手绘插画风 | 温暖笔触、有机形状 | 文创、餐饮、生活服务 |
| 摄影实景 | 真实场景照片、自然光影 | 餐饮、地产、旅游 |
| 国潮 | 传统纹样、朱红金色、书法感 | 文化、节庆、国货品牌 |
| 大字报促销 | 高饱和色块、超大字号、价格醒目 | 电商促销、门店活动 |

## 5. 文字层级规范

- 按场景确定视觉重点，主标题通常醒目，但促销价格或品牌主视觉也可作为主焦点。
- 副标题、卖点和条件说明保持层级，字号根据实际展示尺寸确定，不强制固定比例。
- 在最终交付尺寸及实际阅读宽度检查小字。手机传播默认用 390 像素宽预览；联系信息和优惠条件不得为了简洁变成不可读装饰。以 1200 像素宽画布、19 像素字号为例，缩到 390 像素仅约 6.2 像素，应调整版式和字号，不能只提高导出分辨率。
- 同系列复用品牌配置和稳定标题/正文层级；深浅主题可以变化，Logo 比例、品牌事实和指定颜色规则仍保持一致。
- 优先控制在 3–4 个视觉层级；字数按信息需求与排版能力调整。必保留原文优先，长文案采用专用排字流程。
- 用户指定精确像素时按实测宽高校验。印刷另核实物理尺寸、出血和颜色要求，不以“高清”代替规格。

## 6. 图标与功能展示区

- 有多个真实卖点时可用图标网格；只有一两个卖点时按实际数量布局，也可用列表或局部标注。文案长度按含义决定，不为网格数量补造功能。
- 图标风格与整体风格一致（线性图标配简约风，面性图标配插画风）
- 每个卖点之间留出明显间隔，禁止文字贴边
