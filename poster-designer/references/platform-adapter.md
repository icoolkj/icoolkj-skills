# 平台适配协议

每次图片任务按宿主实际能力填写下表，不调用不存在的工具，不依赖固定模型。能力未知与能力不支持分开记录。

| 能力 | 核实内容 | 不具备时 |
|---|---|---|
| 生成 | 授权、支持的输入、输出与错误格式 | 输出方案和提示词 |
| 图片读取 | 能否查看输入及实际输出图片 | 不推断素材细节；视觉检查记未验证 |
| 参考图 | 输入数量、文件/URL、角色和限制 | 用已知的文字风格描述，保真要求降级 |
| 图像编辑 | 底图输入、区域控制、尺寸与保持限制 | 不承诺局部修改不影响其他区域 |
| 确定性合成/排字 | 原素材叠加、字体可用性和使用限制 | 原版 Logo、精确排字要求未满足时交草稿 |
| 元数据/导出 | 实际宽高、格式、颜色模式、导出能力 | 无法测量则尺寸未验证；不声称印刷就绪 |
| 交付 | 本地文件、平台附件或可访问 URL | 仅报告实际可访问产物 |
| 费用与预算 | 每次计费、重试计费、宿主告知规则 | 费用未知时明确说明，仍遵守授权约束 |

执行顺序：

1. 阅读当前工具 schema / 宿主文档，选择符合任务的能力；不靠名称推断能否生图或编辑。
2. 将核心要求映射为实际参数：目标宽高、图像角色、提示词、底图、输出位置。负面提示词无专用字段时合并自然语言，不传未支持字段。
3. 用户要求精确尺寸时，先评估支持范围。后处理需保持比例、禁止拉伸产品或 Logo。裁切会损失内容时改用留边/重新布局；要求改变时说明偏差，不静默交付近似尺寸。单纯放大不等于提升真实细节。
4. 调用前遵守费用告知；遵循 SKILL.md 的统一尝试上限和累计记录。遇到预算不足不自动超支。
5. 保留工具返回的产物位置、任务标识和实际状态。超时/未知状态先检查原任务，不能盲目重复调用。鉴权、权限或输入错误先解决原因，不反复重试。
6. 查看最终合成/编辑后的文件，核实宽高与真实格式。源图看过不等于最终图检查通过。
7. 用宿主交付方式展示实际文件或附件。仅有远程附件时记录附件来源和可访问性证据，不伪造本地文件路径。

## 保真制作

- 严格 Logo：直接叠加用户原文件，保持比例、色彩和安全区。记录源文件及合成输出。参考图生图仅能作为草稿；不把视觉相似写成原样保留。
- 精确文字：有排字能力时用实际可用且适用于该用途的字体渲染，核对换行、标点、单位及字形；能力不足时保留排版方案和原文。
- 二维码：原码等比叠加，或从用户指定目标确定性编码；检查静区、像素及实际解码目标。不能完成扫码验证则此项未验证。
- 商品/软件：保留实际图片中的外观与界面事实；装饰性 AI 图不冒充真实截图或实拍。
- 印刷：记录毫米尺寸、分辨率、出血、色彩和印厂要求。缺少任一必要规格或导出能力时，只交付数字版/印刷草稿；不能因“高清”或设置 DPI 标签就声称可印刷。

本协议是适配指令，不内置生成、合成、OCR 或印刷引擎。缺少宿主能力时按状态降级，不假装这些能力已安装。
