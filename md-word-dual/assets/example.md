# 双层文档示例

这是一份演示用的 Markdown，用来验证 **Markdown → Word → Markdown** 的完整链路。
转换后双击 `.docx` 看到的是排好版的 Word；用 `docx2md.py` 读回来，得到的就是你现在看到的这份原文，一个字都不差。

## 四、代码块

```python
def normalize(text: str) -> str:
    """去掉首尾空白，压缩中间换行。"""
    return " ".join(text.split())


print(normalize("  a\n b  "))
```

## 五、表格

| 场景 | 推荐做法 | 命令 |

| 交付给业务方 | 生成双层 docx | `md2docx.py 文档.md` |

| 验收 | 往返校验 | `dualdoc.py roundtrip 文档.md` |
