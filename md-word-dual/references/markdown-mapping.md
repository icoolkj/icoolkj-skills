# Markdown ⇄ Word 语法映射表

本表说明每一种 Markdown 语法在 docx 里长什么样，以及「结构化反解」时如何还原。
注意：**走隐藏层时不需要还原**，原文逐字节取回；本表只对两种情况有意义——
① 你手动改过 Word 内容后想取回 Markdown；② 处理别人给的普通 docx。

| Markdown | Word 呈现 | 反解回 Markdown 的判据 |
| --- | --- | --- |
| `# 一级标题` | Heading 1 样式，带下边框，进导航窗格 | 段落样式 `Heading1` / 名称 `heading 1` |
| `##` ~ `######` | Heading 2~4（5、6 级统一降为 Heading 4） | 同上，取样式名里的数字 |
| 普通段落 | Body Text 样式，1.4 倍行距，段后 7pt | 无特殊样式的段落 |
| `**加粗**` | 加粗 run | run 带 `<w:b/>` |
| `*斜体*` | 斜体 run | run 带 `<w:i/>` |
| `~~删除线~~` | 带删除线 run | run 带 `<w:strike/>` |
| `` `行内代码` `` | Consolas + 红字 + 浅灰底 | run 的 `rFonts` 为 Consolas |
| `[文字](url)` | 蓝色下划线超链接，可点 | `<w:hyperlink>` + 关系表里的目标地址 |
| `![说明](图.png)` | 按原比例嵌入，超版心宽度自动缩放 | `<w:drawing>` + `r:embed` 指向 media |
| `- 项目` | 项目符号列表（•/◦/▪ 三级） | 段落 `numPr` + 编号表该层 `numFmt=bullet`；段落没写 `numPr` 时沿 `basedOn` 链找样式定义里的编号（`List Bullet` / `List Number` 就是这种写法） |
| `1. 项目` | 数字编号，每个列表从 1 重新开始 | `numFmt=decimal`，按 numId+ilvl 累加 |
| 缩进 2 空格 | 列表降一级 | `ilvl` 值 |
| `> 引用` | 左侧竖线 + 浅灰底 + 缩进 | 段落样式名为 `Quote`/`Intense Quote`，或段落 `pBdr` 带 `left` 竖线 |
| ```` ```lang ```` | 带边框和底纹的等宽代码块，整块一个段落，行间用软换行 | 段落样式 `CodeBlock`；或「段落有底纹 + 全部 run 为等宽字体」——只看底纹会把引用块误判成代码，所以两者必须同时满足 |
| 表格 | 真实 Word 表格，首行加粗带底色，跨页时首行重复 | `<w:tbl>`，首行作表头 |
| `---` | 一条细横线（段落下边框） | 不还原为 `---`，视为空段落丢弃 |
| `<br>` | 单元格内换行 | 单元格内 `<w:br/>` |

## 不支持的语法

遇到时按**纯文本**照抄，不报错、不丢内容（因为原文还在隐藏层里）：

- 脚注 `[^1]`、定义列表、任务列表的勾选框 `- [ ]`
- 数学公式 `$...$`、HTML 块级标签
- 引用式链接 `[a][b]` 与自动链接 `<https://...>`
- `[TOC]` 目录标记（要目录请用 `--toc` 参数，Word 里右键更新域）

## 双向保真度说明

| 动作 | 保真度 |
| --- | --- |
| md → docx → md（走隐藏层） | 逐字节一致 |
| md → docx → 改 Word 内容 → md | 按上表反解，代码块语言标识会丢失，其余结构保留 |
| 普通 docx → md | 依赖对方的样式与格式：标准标题样式、样式或段落上的编号、底纹、左边框都能识别；纯手工排版（逐段手动加粗、手动敲 `1.`）只能得到段落流。若对方连行内代码的文字都没写进 docx，任何工具都救不回来 |
