# 选题生成公式

> NoteIntel references — 创作选题的角度挖掘与受众匹配

---

## 1. 角度挖掘方法

### 1.1 六大切入角度

从核心事实出发，可从以下六个角度挖掘创作选题：

| 角度 | 核心问题 | 适用场景 |
|------|----------|----------|
| **数据冲击** | 这个数字为什么让人意外？ | 含反直觉数据、突破性记录 |
| **对比反差** | A和B之间的差距说明了什么？ | 含对比数据、排名变化 |
| **因果追溯** | 为什么会发生这个？背后原因是什么？ | 含因果关系、趋势变化 |
| **影响推演** | 这件事会影响到谁？影响多大？ | 含政策、行业变化 |
| **方法拆解** | 他们是怎么做到的？方法可复制吗？ | 含方法论、成功案例 |
| **趋势预判** | 这个趋势会怎么发展？下一步是什么？ | 含趋势数据、预测性结论 |

### 1.2 角度选择规则

- 每条选题选择一个主角度，不混合多个角度
- 同一事实可从不同角度生成多条选题，但需确保角度差异明显
- 优先选择与事实关联最强的角度
- 避免选择原文已明确阐述的角度（缺乏增量价值）

### 1.3 角度与事实的匹配

| 事实特征 | 推荐角度 |
|----------|----------|
| 含反直觉数据 | 数据冲击 |
| 含对比/排名 | 对比反差 |
| 含因果表述 | 因果追溯 |
| 含政策/行业变化 | 影响推演 |
| 含方法论/案例 | 方法拆解 |
| 含趋势/预测 | 趋势预判 |

---

## 2. 受众匹配策略

### 2.1 受众分类

| 受众类型 | 特征 | 内容偏好 |
|----------|------|----------|
| **行业从业者** | 了解行业基础，关注专业深度 | 深度分析、方法论、数据解读 |
| **投资者/决策者** | 关注趋势和影响，需要决策依据 | 趋势预判、影响推演、投资逻辑 |
| **普通消费者** | 关注与自身相关的影响 | 生活影响、消费建议、通俗解读 |
| **学习者/研究者** | 关注知识获取和体系构建 | 方法拆解、因果分析、知识梳理 |
| **媒体创作者** | 关注选题角度和传播价值 | 话题热点、传播角度、内容灵感 |

### 2.2 受众匹配规则

- 每条选题明确标注目标受众类型
- 受众选择基于事实的内容特征：
  - 技术类事实 → 行业从业者 + 学习者
  - 市场类事实 → 投资者 + 媒体创作者
  - 消费类事实 → 普通消费者
  - 政策类事实 → 行业从业者 + 投资者
- 同一事实可面向不同受众生成不同选题，但内容侧重应有差异

## 3. 内容形式建议

### 3.1 内容形式分类

| 形式 | 适用场景 | 特征 |
|------|----------|------|
| **图文长文** | 深度分析、方法论拆解 | 信息密度高，适合深度模式 |
| **短视频** | 数据冲击、对比反差 | 视觉化呈现，传播力强 |
| **图文卡片** | 单一数据点、核心结论 | 轻量传播，适合精简模式 |
| **系列内容** | 多维度分析、趋势追踪 | 分期发布，适合深度模式 |
| **直播/访谈** | 因果追溯、方法拆解 | 互动性强，适合行业从业者 |

### 3.2 形式判断规则

- 精简模式 → 优先建议图文卡片
- 标准模式 → 优先建议图文长文或短视频
- 深度模式 → 优先建议图文长文或系列内容
- 数据冲击角度 → 短视频或图文卡片
- 方法拆解角度 → 图文长文或直播/访谈
- 影响推演角度 → 图文长文或系列内容

---

## 4. 选题质量标准

### 4.1 必须满足

- 每条选题关联至少一条核心事实（有据可依）
- 切入角度明确且与事实特征匹配
- 目标受众具体且合理
- 内容形式建议与模式和角度匹配

### 4.2 应该避免

- 选题与提取的事实无直接关联（无据可依）
- 角度模糊（如"综合分析"——不是具体角度）
- 受众泛化（如"所有人"——不是具体受众）
- 形式建议与内容特征不匹配（如精简模式建议系列内容）

### 4.3 选题增量价值

好的选题应提供原文中没有直接阐述的视角：

- ✅ "从950万辆看中国新能源汽车的全球定位" — 提供了全球对比的增量视角
- ❌ "中国新能源汽车销量950万辆" — 只是复述事实，无增量价值
